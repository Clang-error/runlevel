# 개인정보 처리방침 (초안 — 화면에서는 뺀 상태)

2026-08-20 에 설정 메뉴에 넣었다가 다시 뺐다. 팝업 폭이 좁아 글이 지저분해서다.
내용 자체는 그때의 사실과 맞다. 다시 넣을 때는 팝업이 아니라 별도 페이지나
홈의 탭처럼 폭이 넉넉한 자리를 쓰는 편이 낫다.

**로그인을 붙이면 이 문서가 의무가 된다.** 식별자를 저장하는 순간
개인정보보호법 제30조의 처리방침 공개 의무가 걸리고, 아래 "받지 않는 것" 문단도
사실과 달라지므로 반드시 고쳐야 한다.

---

받지 않는 것
계정·이메일·이름을 받지 않습니다. 접속 IP 와 기기 식별자를 저장하지 않고,
추적용 쿠키를 쓰지 않으며, 광고나 외부 분석 도구를 넣지 않았습니다.
누가 무엇을 풀었는지는 저희도 알 수 없습니다.
받는 것 — 풀이 기록
문제를 떠날 때 문제 번호, 성공·이탈 여부, 터미널에 친 명령, 걸린 시간,
힌트를 몇 번 봤는지, 목표를 몇 개 통과했는지를 한 건 남깁니다.
어느 문제가 유독 어려운지, 어디서 다들 막히는지를 보고 문제를 고치는 데 씁니다.
설정 → 힌트, 정답, 로그전송 → 풀이 기록 보내기를 끄면 보내지 않습니다.
받는 것 — 문제 신고
신고를 보내실 때만, 직접 쓰신 글과 어느 화면에서 보냈는지가 저장됩니다.
터미널 기록 함께 보내기를 체크하신 경우에 한해 그 화면에서 오간 내용이 함께 갑니다.
체크를 풀면 글만 갑니다. 재현이 안 되면 고칠 수가 없어서 두었습니다.
진도는 이 브라우저에만 있습니다
어느 문제를 풀었는지는 브라우저 저장소(localStorage)에만 남고 서버로 오지 않습니다.
그래서 브라우저를 바꾸시면 진도가 따라오지 않습니다.
설정 → 진도 초기화로 언제든 지우실 수 있습니다.
어디에 보관하나
Cloudflare D1 에 저장합니다. 원본을 조회하는 창구는 웹에 두지 않았고,
개발자가 직접 접속해서만 볼 수 있습니다. 밖으로 제공하거나 판매하지 않습니다.
따로 정해 둔 보관 기간은 없으며, 문제를 고치는 데 더 쓸모가 없어지면 지웁니다.
